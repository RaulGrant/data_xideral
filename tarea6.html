Pipeline de limpieza serverless con Lambda, S3 y EventBridge

Esta pagina presenta un pipeline compuesto por dos funciones Lambda que leen un CSV desde S3, limpian el dataset y generan un reporte JSON con el conteo final de filas.

Stack del flujo

Arquitectura simple, automatizada y sin servidores permanentes.

Funciones Lambda encadenadas por el flujo del pipeline.

Frecuencia de ejecucion programada con EventBridge.

Flujo del pipeline

De CSV crudo a reporte JSON

El proceso corre de forma automatica y deja el bucket organizado por etapas.

Input · S3 bucket alumnos_escuela.csv Archivo original en la raiz del bucket.
→
Lambda 1 Limpieza + dataset_utils.py Elimina nulos y duplicados del DataFrame.
→
Output + reporte CSV limpio + JSON final clean_data/ y result/ dentro del mismo bucket.
Trigger programado: ambas Lambdas usan Amazon EventBridge con la expresion rate(5 minutes). Lambda 1 toma el CSV base, genera el archivo limpio en clean_data/ y despues Lambda 2 consume ese resultado para producir el JSON en result/.
Arquitectura funcional

Rol de cada componente

Separar limpieza y reporte mantiene el flujo claro y reusable.

Lambda 1 · Limpieza del dataset

Lee alumnos_escuela.csv desde S3, delega la transformacion al modulo auxiliar dataset_utils.py y escribe el resultado limpio en clean_data/.

  • Obtiene el bucket desde la variable de entorno BUCKET_NAME.
  • Convierte el contenido a DataFrame con pandas.
  • Guarda el CSV procesado sin indice.

Lambda 2 · Conteo y reporte JSON

Lee el CSV limpio desde clean_data/, cuenta sus filas y genera un archivo JSON en result/ con el nombre procesado y el total encontrado.

  • Soporta eventos de S3 o fallback para prueba manual.
  • Arma el nombre del resultado con os.path.basename.
  • Publica el archivo con ContentType application/json.

lambda2.py Python · AWS Lambda 
import json
import boto3
import urllib.parse

s3 = boto3.client("s3")
def lambda_handler(event, context):
    # 1. Obtener información del evento de S3 y decodificar la ruta
    bucket = event['Records'][0]['s3']['bucket']['name']
    key = urllib.parse.unquote_plus(event['Records'][0]['s3']['object']['key'])
    
    # 2. Solo procesar si es el archivo que nos interesa
    if key == "clean_data/clean.csv":
        print(f"Procesando archivo: {key}")
        
        # Leer el archivo CSV
        response = s3.get_object(Bucket=bucket, Key=key)
        lineas = response["Body"].read().decode("utf-8").splitlines()
        
        # Calcular el total (restando encabezado)
        total_alumnos = len(lineas) - 1 if len(lineas) > 0 else 0
        
        # Crear el diccionario de resultados
        resultado = {
            "archivo_origen": key,
            "total_alumnos": total_alumnos,
            "estado": "procesado"
        }
        
        # 3. Guardar el JSON en la carpeta 'result/' con el nombre 'result.json'
        target_key = "result/result.json"
        
        s3.put_object(
            Bucket=bucket,
            Key=target_key,
            Body=json.dumps(resultado),
            ContentType='application/json'
        )
        
        print(f"Resultado guardado en {target_key}: {resultado}")
        
        return {
            'statusCode': 200,
            'body': json.dumps(f"Conteo guardado exitosamente en {target_key}")
        }
    
    return {
        'statusCode': 200, 
        'body': json.dumps(f"Archivo {key} ignorado")
    }
